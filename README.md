# Expense Tracker CLI — Python Project

## 📌Project Description📌

Expense Tracker CLI is a command-line application built with Python that allows users to manage, track, and organize personal expenses.

The application supports adding, updating, deleting, and viewing expenses, along with generating spending summaries, setting monthly budgets, and exporting records to CSV files.

Expense data is stored locally using JSON, ensuring information persists between sessions. The application uses Python's argparse module to handle commands and user input.

🎯 Project Focus

CLI Development — Building a command-line interface using Python's argparse module.

CRUD Operations — Creating, reading, updating, and deleting expense records.

Data Persistence — Storing and managing financial data using JSON.

Data Processing — Calculating expenses, filtering by month, and tracking budgets.

File Handling — Reading, writing, and exporting data using JSON and CSV.

Python Fundamentals — Applying functions, loops, dictionaries, lists, and conditional logic.

⚙️ Application Features

Add Expense — add_cmd()

Records expenses with a unique ID, date, description, and amount.

Update Expense — update_cmd()

Modifies existing expense details using their unique ID.

Delete Expense — delete_cmd()

Removes expenses from stored records.

List Expenses — list_cmd()

Displays all recorded expenses in a readable format.

Expense Summary — summary_cmd()

Calculates total spending and generates monthly summaries.

Monthly Budget — budget_cmd()

Sets monthly spending limits and warns when budgets are exceeded.

Export Expenses — export_cmd()

Exports expense records into CSV files for use in spreadsheet applications.

🛠️ Technologies Used

argparse — Command-line interface and argument parsing.

datetime — Date management and monthly filtering.
